Инструмент "Схема запроса 1С"

Назначение
Инструмент предназначен для визуализации структуры запросов на языке запросов 1С и SQL запросов. Он автоматически строит наглядную диаграмму потоков данных, отображая таблицы-источники, их соединения (включая декартово произведение), объединения, вложенные запросы, временные таблицы и итоговые выборки. 

Основные возможности
  • Поддержка синтаксиса: построение схемы на основе текста запросов 1С (в т.ч. версии 8.3.25) и SQL из технологических журналов.
  • Автономность: формирование схемы запроса происходит без необходимости инициализации описанных данных в базе, где запущен инструмент.
  • Два режима визуализации: классическая схема (PlantUML) и интерактивный граф (vis.js).
  • Настройка отображения: доступны параметры для подбора наиболее наглядного варианта визуализации.
  • Сохранение результата: возможность сохранить итоговую схему в виде SVG-файла (для режима PlantUML).
Особенности
  • Для корректной обработки все таблицы должны иметь синонимы, а обращения к полям должны происходить через эти синонимы.
  • Построение диаграммы в режиме PlantUML выполняет внешний сервис, развернутый на сервере компании «1С-Рарус», что требует наличия интернет-соединения. Интерактивный режим работает офлайн.
